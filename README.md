## 📌 About RoadsRiser

RoadsRiser is a full-stack roadside assistance platform designed to connect vehicle owners with mechanics when they need help during a vehicle breakdown or roadside emergency.

The platform provides separate experiences for:

- 👤 Vehicle Owners
- 🔧 Mechanics
- 🛡️ Administrators

RoadsRiser covers the complete service-request lifecycle, from creating a roadside assistance request to mechanic assignment, status tracking, service completion, history and mechanic earnings.

---

## 🎯 The Problem

Vehicle breakdowns can happen unexpectedly, and finding roadside assistance quickly can be difficult.

A vehicle owner may need help with:

- Engine starting problems
- Dead battery
- Tyre puncture
- Empty fuel tank
- Overheating
- Brake problems
- Electrical faults
- Towing
- Other roadside issues

RoadsRiser aims to simplify this process by providing a centralized platform where users can request assistance and mechanics can discover and handle service requests.
